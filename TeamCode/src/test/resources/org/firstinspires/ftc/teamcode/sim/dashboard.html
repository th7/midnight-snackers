        Op modes

        Each run rebuilds the sources as last saved, so a saved edit is what runs next. Place first to choose where the robot starts, and set a seed to choose which robot: each seed is its own imperfect robot, the same one every run, and a blank seed is the exact tuned model. Each op mode remembers its place and its seed. A TeleOp is driven from the controller under the live view.

        A game is played as a match is: an auto has the autonomous period and a TeleOp the driver-controlled period, and you watch your robot from where the alliance’s drivers stand. Otherwise a run goes on until its plan is done or you press Stop.
